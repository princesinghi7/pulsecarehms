# PulseCare 🏥

PulseCare is an AI-powered Hospital Management System designed to simplify hospital workflows through automation, smart scheduling, digital health records, and real-time analytics.

## 🚀 Features
- User Authentication (Admin, Doctor, Patient)
- Appointment Booking System
- Patient Management
- Doctor Dashboard
- Billing & Invoice Management
- AI Symptom Checker
- AI Chatbot Support
- Emergency Booking System
- Digital Health Records
- Real-time Dashboard Analytics
- Email/Notification Alerts

## 🛠 Tech Stack
### Frontend
- Angular
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- JWT Authentication
- Socket.io
- Cloudinary

## ⚙ Installation

### Clone repository
```bash
git clone https://github.com/yourusername/pulsecare.git
cd pulsecare
```

### Backend setup
```bash
cd backend
npm install
npm start
```

### Frontend setup
```bash
cd frontend
npm install
ng serve
```

## 🔐 Environment Variables
Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
```
